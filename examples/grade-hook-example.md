# Example: Grade a Hook

**You type:**
> Grade this hook: "Hello everyone, today I want to talk about our gym's new classes."

**The skill replies:**

```
YOUR HOOK: "Hello everyone, today I want to talk about our gym's new classes."
SCORE: 2/10

| Check     | Score | Why                                     |
|-----------|-------|-----------------------------------------|
| Curiosity | 0/2   | Nothing makes people wonder             |
| Clarity   | 2/2   | Easy to understand                      |
| Speed     | 0/2   | Slow start, no point until the end      |
| Relevance | 0/2   | Doesn't say who it's for                |
| Contrast  | 0/2   | No surprise                             |
| Total     | 2/10  |                                         |

BIGGEST FIX: Skip the greeting and start with the viewer's problem.

BETTER VERSIONS
1. Hate the gym? Try this 20-minute class instead. — 9/10
2. If you quit every gym by February, this is for you. — 8/10
3. Treadmill for an hour vs our 20-minute class. — 8/10
```
